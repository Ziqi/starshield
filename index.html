2. Epistemic Discipline: Separating Observed Bytes from Triage Leads

Overstating forensic certainty undermines pre-action credibility. Every output field emitted by starshield-forensics applies a four-tier provenance taxonomy (OBSERVED, DERIVED, INFERRED, UNKNOWN) separating raw byte observations from derived checksums and unverified external state:

Artifact Class Technical Extraction Epistemic Tier Mandatory Boundary & Alternative Explanations
Chromium LevelDB .log UTF-8/UTF-16LE JSON records recovered with physical leveldb_batch_byte_offset alongside deletetime OBSERVED Reflects uncompacted local write-ahead cache only; records already garbage-collected by Chromium compaction cannot be quantified from client storage alone.
Financial Identifiers ISO/IEC 7812 Luhn check-digit verification & ISO 13616 IBAN Mod-97 country-length validation DERIVED Confirms mathematical check-digit validity and intra-message proximity (≤120 chars), not account ownership or settlement completion.
PNG / JPEG Containers CRC-verified PNG iCCP / multi-chunk JPEG APP2 ICC headers (acsp) and APP13/8BIM offsets DERIVED Consumer OS screenshot pipelines routinely embed Display P3 or sRGB profiles; container metadata indicates pipeline touch, never standalone proof of document forgery.
Session & UTC Intervals Timezone-aware ISO-8601 delta calculation rejecting naive timestamps and negative clock skew DERIVED / INFERRED Cross-endpoint intervals depend on NTP clock synchronization; CDN/edge tags reflect network routing rather than physical operator geolocation.
