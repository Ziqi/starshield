## 中文说明（StarShield 在线文档与脱敏取证底稿门户）

本仓库承载 **[`starshield-forensics`](https://github.com/Ziqi/starshield-forensics)**（获颁 Linux 基金会 **OpenSSF Best Practices `Silver` 银牌 `#16602`** 的纯离线电子数据取证工具包）的静态文档站点与标准化证据初筛工作底稿示例：

1. **在线门户站点**：[`https://ziqi.github.io/starshield/`](https://ziqi.github.io/starshield/)（由仓库根目录 `index.html` 驱动）。
2. **合成案例示范底稿**：[`Sample_Evidentiary_Triage_Workpaper.pdf`](./Sample_Evidentiary_Triage_Workpaper.pdf) 展示了如何按 `OBSERVED` / `DERIVED` / `INFERRED` / `UNKNOWN` 四级认知标准向律所与调查机构呈现技术初筛结论（内含数据 100% 为净室虚构测试向量）。
3. **源码安装与使用**：请前往主代码仓 **[`Ziqi/starshield-forensics`](https://github.com/Ziqi/starshield-forensics)** 或直接执行 `pip install starshield-forensics`。
