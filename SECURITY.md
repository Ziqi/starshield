# Security Policy

To report a security issue affecting the **StarShield** documentation portal (`ziqi.github.io/starshield`) or the **`starshield-forensics`** Python package, please use **[GitHub Private Vulnerability Reporting](https://github.com/Ziqi/starshield/security/advisories/new)** (or [starshield-forensics Security Advisories](https://github.com/Ziqi/starshield-forensics/security/advisories/new)).

- **Acknowledgement SLA:** Within 48 hours
- **Core Library Assurance Case:** See [`Ziqi/starshield-forensics/SECURITY_ASSURANCE_CASE.md`](https://github.com/Ziqi/starshield-forensics/blob/main/SECURITY_ASSURANCE_CASE.md)
