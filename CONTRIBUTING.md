# Contributing to StarShield Portal

Improvements to documentation clarity, accessibility, and synthetic workpaper templates are welcome via Pull Request:

1. Do **not** alter `scorecard.json` manually or break live GitHub Pages assets (`index.html`, `.nojekyll`).
2. Never submit real incident artifacts or personally identifiable information (PII); all examples must use 100% synthetic test vectors.
3. Sign off commits via `git commit -s` under the MIT License.
